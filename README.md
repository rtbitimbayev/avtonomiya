# Автономия — «Один день выжившего»

Играбельный вертикальный срез существующей игры: один выживший, строго верхний вид, программный pixel art, Phaser 3 + TypeScript strict + Vite. Без внешних ассетов, CDN, сетевых API или дополнительных игровых фреймворков.

## Запуск

Node.js 22.12+ (проверено на Node 24):

```sh
npm ci
npm test
npm run dev
```

Откройте адрес Vite. `npm run build` проверяет TypeScript и собирает `dist/`; `npm run preview` запускает production-сборку. При недоступном домашнем npm-кеше: `npm ci --cache /tmp/avtonomiya-npm`.

## Один день выжившего

Вы появляетесь южнее заброшенного убежища. Карта **64×64**, тайл **32×32**, мир **2048×2048**. Путь и стартовая зона свободны; в остальном мире оставлена связная сетка проходов. Деревья, обломки, камни, бочки и убежище имеют физические коллизии.

- **WASD / стрелки** — движение со скоростью **150 пикселей/с**; диагональное движение нормализовано. Персонаж поворачивается и меняет кадры idle/walk. Камера следует за ним и ограничена миром.
- **E** — ближайшее доступное взаимодействие в радиусе **48 пикселей от центра персонажа**. Одно действие на нажатие, удержание не повторяет сбор. Подсказка появляется только в пределах радиуса, объект выделяется.
- Сухое дерево к западу от старта: **+3 дерева**.
- Металлолом к востоку: **+2 металла**.
- Бочка с водой к югу: **+1 воды**.
- Собранный объект и его коллизия исчезают; повторно добыть его нельзя. Камни — только препятствия.
- Вернитесь к убежищу с тремя видами припасов и нажмите **E**. Сообщение: **«Убежище. Здесь можно отдохнуть»**. Журнал отметит завершение дня. После этого можно продолжать исследование.

Ближайшие цели указаны в журнале: дерево 29:35, металл 35:34, вода 33:38, убежище 32:31. Начальная позиция — 32:35. Заходить внутрь, спать или ждать реального заката не требуется: «Вернуться до темноты» — название задачи, таймера поражения в этом спринте нет.

HUD закреплён на экране: три счётчика, журнал, подсказки и управление. Canvas меняет размер вместе с окном, пиксельные текстуры используют nearest filtering без размытия. Целевые размеры экрана — 1366×768 и 1920×1080. Для движения нужна клавиатура; сенсорное управление не добавлялось.

## Сохранения и прежнее хозяйство

**Сохранение и загрузка выполняются только по кнопкам. Автозаписи нет в обоих режимах.** Новый поход начинается с нуля при открытии страницы; для продолжения сохранённого похода нажмите «Загрузить».

Выживший использует отдельный ключ `avtonomiya-survivor-v1`: позиция, собранные объекты, счётчики и возврат. Он не читает и не изменяет сохранение хозяйства `avtonomiya-v1`. При загрузке проверяются версия, seed, ресурсы, уникальность собранных объектов, границы и отсутствие препятствия в точке появления. Повреждённые или несовместимые данные показывают сообщение; текущая игра и исходное сохранение сохраняются без изменений. Если хранилище браузера недоступно, ручное сохранение сообщает об ошибке.

Кнопка **«Хозяйство ↗»** открывает прежнюю игру (`#farm`): строительство, многоклеточные здания, грядки, куры, логистика, энергия, два уровня и миграция v0.1 сохранены. Обратная кнопка — **«Выживший»**. Перед переключением вручную сохраните текущий режим; переход перезагружает страницу. [Документация хозяйства](docs/farming.md).

Как и раньше, localStorage привязан к браузеру и адресу. Локальная и опубликованная игры имеют разные сохранения.

## Изменения архитектуры

Существующие `data.ts`, `simulation.ts`, `renderer.ts`, `indicators.ts` и тесты хозяйства сохранены. Прежняя точка входа перенесена в `src/farming.ts`, `src/main.ts` выбирает режим и загружает его динамически.

Новый код:

- `src/survival/ResourceData.ts` — типизированные счётчики, детерминированные объекты, скорость, границы, состояние и валидация сохранения; без Phaser и DOM.
- `src/survival/InteractionSystem.ts` — ближайшая цель, радиус, одноразовая добыча и завершение задачи; без графики.
- `src/survival/Player.ts` — Arcade Physics, клавиатура, нормализованная скорость, направление и анимация по delta time.
- `src/survival/WorldMap.ts` — карта, реальные статические тела препятствий и удаление собранных объектов.
- `src/survival/textures.ts` — временные пиксельные текстуры, генерируемые локально.
- `src/survival/HUD.ts` и `survival.css` — экранный интерфейс и обратная связь.
- `src/survival/GameScene.ts` — связывает эти компоненты, камеру, коллайдер, ввод E и команды сохранения.
- `src/survival/survival.test.ts` — генерация, свободный старт, движение, радиус и ближайшая цель, точные награды, повторный сбор, задача и изоляция сохранений.

`npm test` запускает **31 тест**: 26 существующих и 5 для выжившего. В движении скорость задаётся в пикселях/секунду, интеграцию по времени выполняет Arcade; кадры ходьбы используют переданный delta time. При потере фокуса движение сбрасывается. Компоненты карты освобождаются при загрузке нового состояния.

## GitHub Pages

Совместимость сохранена: `base: './'`, относительные ссылки, никаких абсолютных путей к текстурам. Workflow `.github/workflows/pages.yml` по push в `main` запускает `npm ci`, тесты, сборку и публикацию `dist/`.

1. В **Settings → Pages → Source** должен быть выбран **GitHub Actions**.
2. После отправки изменений дождитесь зелёных **build** и **deploy** в **Actions → Publish game to GitHub Pages**. При необходимости: **Run workflow → main → Run workflow**.
3. Откройте **https://rtbitimbayev.github.io/avtonomiya/** и обновите страницу **Ctrl+Shift+R**. Должен появиться заголовок **«ОДИН ДЕНЬ ВЫЖИВШЕГО»**, персонаж и тёмный HUD.
4. Старый режим остаётся по адресу **https://rtbitimbayev.github.io/avtonomiya/#farm**.

## Границы спринта

Только сбор, исследование и возвращение. Не добавлены враги, бой, голод, крафт, оружие, сложный инвентарь, вход внутрь убежища или сон. Физика работает по прямоугольным телам; pixel-art временный. Данные мира отделены от отображения для дальнейшего расширения, но размеры этого среза намеренно фиксированы.
