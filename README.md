# Автономия

Первая играбельная версия браузерной песочницы: хозяйство без управляемых жителей. TypeScript, Phaser 3, Vite; вся графика рисуется программно, без внешних ресурсов.

## Запуск

Нужен Node.js 22.12+ (проверено на 24).

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. `npm run build` проверяет TypeScript и создаёт `dist/`; `npm run preview` запускает собранную версию. `npm test` запускает 7 тестов симуляции. Если домашний npm-кеш недоступен, используйте `npm ci --cache /tmp/avtonomiya-npm`.

## Первая цепочка

1. Постройте склад в центре карты. Вплотную к нему поставьте грядку и водосборник. Все объекты, соединённые сторонами клеток, образуют сеть склада; конвейеры позволяют протянуть её дальше. Сети разных уровней независимы.
2. Грядка с семенами уже посажена при строительстве. В сети она получает воду, собирает урожай и сеется заново автоматически. Без сети выберите её и нажмите «Посадить / полить», затем «Собрать урожай». Рост занимает 60 секунд при достаточном свете и воде; удобрение ускоряет его в 1,7 раза. Урожай: 8 еды и 2 семени.
3. Подключите кормушку и поставьте рядом курятник. Две курицы расходуют по 2 еды и воды за 24 секунды и производят 2 яйца и 2 навоза. Голод останавливает производство и снижает здоровье; снабжение его восстанавливает. Вручную также можно пополнить запасы курятника и забрать продукцию.
4. Компостер превращает 3 навоза в 2 удобрения за 18 секунд. В сети склад сам забирает продукцию и доставляет удобрения грядкам.

Водосборник производит 1 воду за 3 секунды, рядом с водой — за секунду. Без связи со складом его ёмкость ограничена 50 единицами. Изолированные кормушки и компостеры пополняются кнопкой в панели объекта.

## Управление

- Каталог слева → щелчок по свободной клетке: строительство с оплатой ресурсов.
- «Выбор» → объект: состояние, запасы, ручное обслуживание.
- «Добыча» → дерево: 12 дерева; камень: 10 камня и 2 металла; вода: 10 воды.
- «Снос» → постройка: возврат половины стоимости с округлением вниз и всех внутренних запасов. Для грядки возвращается половина исходной стоимости, включая семена, по тому же правилу.
- WASD / стрелки: камера. Колесо: масштаб. «К центру»: возврат. Esc: режим выбора.
- Кнопки уровней: поверхность / подземелье −1. Начальная подземная комната открыта; «Добыча» расширяет её от открытой клетки за 2 дерева, давая 6 камня.
- Грядкам под землёй нужен светильник в радиусе 4 клеток. На поверхности растения растут с 06:00 до 20:00; светильник позволяет выращивать ночью.
- Пауза и скорости ×1 / ×2 / ×4 управляют всей симуляцией. Одна реальная секунда на ×1 соответствует двум игровым минутам.
- Сохранение и загрузка — кнопками вверху. Автосохранение каждые 30 реальных секунд; сохранение загружается при открытии. Данные хранятся только в localStorage этого браузера и адреса. Симуляция закрытой вкладки не рассчитывается. Ошибка хранилища показывается при ручном сохранении.

Начальные ресурсы: 100 дерева, 60 камня, 30 металла, 20 семян, 50 воды, 40 еды. В сети нет ограничений пропускной способности: передача мгновенная. Яйца пока накапливаются как продукция, торговля и новые рецепты не реализованы.

## Модули

- `src/simulation.ts` — детерминированная генерация двух карт 64×64, экономика, производство, сеть, сериализация. Не зависит от Phaser и DOM; `tick(dt)` принимает игровое время в секундах, до 1 секунды на шаг.
- `src/main.ts` — сцена Phaser, рисование, камера, интерфейс и преобразование пользовательских команд в действия симуляции.
- `src/style.css` — адаптивный интерфейс.
- `src/simulation.test.ts` — проверка стоимости, ограничений, роста, снабжения, переработки, освещения и сохранений.

Схема сохранений имеет версию 1. Структурно повреждённые сохранения отклоняются. Внешние сервисы и ключи не нужны.

## Публикация в GitHub Pages

Подготовлен workflow `.github/workflows/pages.yml`. Он устанавливает зависимости по lockfile, запускает тесты, собирает игру и публикует `dist/`. Относительные пути Vite поддерживают размещение в `/avtonomiya/`.

1. Сохраните все файлы проекта в репозитории `rtbitimbayev/avtonomiya` и отправьте их в ветку `main`, включая `.github/workflows/pages.yml`, `vite.config.ts`, `src/`, `package.json`, `package-lock.json`, `tsconfig.json` и `index.html`.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
3. Откройте **Actions → Publish game to GitHub Pages → Run workflow → main → Run workflow**. Последующие отправки в `main` публикуются автоматически.
4. После успешного задания `deploy` нажмите ссылку в его блоке `github-pages` или **Settings → Pages → Visit site**. Ожидаемый адрес: https://rtbitimbayev.github.io/avtonomiya/ . Он станет доступен после первой успешной публикации.

Для Pages может понадобиться публичный репозиторий либо тариф GitHub с поддержкой Pages для приватных репозиториев. Сохранения в опубликованной игре отделены от локальной версии, поскольку localStorage привязан к адресу сайта.
