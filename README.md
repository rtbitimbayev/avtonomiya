# АВТОНОМИЯ: Последний рубеж

Спринт №2 — **«Цена выживания»**. Существующая игра на Phaser 3, TypeScript strict и Vite: один персонаж на карте 64×64, ресурсы и убежище, теперь со здоровьем, голодом, жаждой, часами, ночью и сном. Pixel-art генерируется локально; внешние ассеты и CDN не нужны.

## Запуск

Нужен Node.js 22.12+ (проверено на 24).

```sh
npm ci
npm test
npm run dev
```

`npm run build` — проверка TypeScript и production-сборка в `dist/`. `npm run preview` — запуск собранной игры. Если домашний npm-кеш недоступен, используйте `npm ci --cache /tmp/avtonomiya-npm`.

## Управление

- **WASD / стрелки** — движение, **E** — ближайшее взаимодействие до 48 пикселей.
- **1** — 1 еда, +35 сытости; **2** — 1 вода, +45 жажды. Не расходуются при полной шкале; удержание не повторяет употребление.
- **P / «Пауза»** — остановить или продолжить игру. Неактивная вкладка тоже останавливает движение и часы.
- У убежища **E** открывает осмотр, сон на 6 часов и отмену. **Esc** закрывает обычное меню.
- **Сохранить / Загрузить** — текущий поход. Автосохранение после значимых действий и каждые 30 активных секунд. Смерть не затирает последнее живое состояние.
- **Хозяйство ↗** — прежний режим строительства и производства (`#farm`). Его сохранения независимы, [документация хозяйства](docs/farming.md).

Новая игра начинается в день 1, 08:00: здоровье, сытость и жажда по 100, еда 3, вода 2. Секунда активной игры равна игровой минуте. Полная сытость расходуется за 16 часов, вода — за 8. При нулевых шкалах теряется соответственно 4 и 8 HP/час, вместе 12. Сон не лечит и учитывает точное время истощения организма.

Дерево к западу от старта: +3; металл к востоку: +2; бочка южнее: +1 воды. Пакеты еды: **30:37, 36:36, 29:32, 34:30, 36:39**, по +1. Убежище — **32:31**, старт — **32:35**. Камера следует за игроком, твёрдые объекты блокируют путь. Журнал первого спринта сохранён; завершение задачи не прекращает выживание.

## Совместимость

Новый snapshot имеет `schemaVersion: 2`, ключ `avtonomiya-survivor-v2`. Валидные походы первого спринта мигрируют с сохранением позиции, собранных ресурсов и исходного ключа. Повреждённые/несовместимые данные не затираются: предлагается безопасная новая игра с резервной копией либо игра без записи. Данные хозяйства `avtonomiya-v1` не затрагиваются. localStorage зависит от браузера и адреса сайта; локальная версия и Pages имеют разные данные.

Чистая логика отделена от Phaser: баланс, время, организм, употребление и сохранения — отдельные модули; Player, WorldMap, InteractionSystem и HUD первого спринта расширены. **46 тестов** проверяют хозяйство и оба спринта выжившего.

## GitHub Pages

`base: './'` и существующий `.github/workflows/pages.yml` сохранены. Push в `main` запускает `npm ci` → тесты → сборку → публикацию.

Адрес: **https://rtbitimbayev.github.io/avtonomiya/**. Старый режим: **https://rtbitimbayev.github.io/avtonomiya/#farm**.

В **Settings → Pages → Source** должен быть выбран **GitHub Actions**. После push дождитесь зелёных `build` и `deploy` в **Actions → Publish game to GitHub Pages**, затем обновите страницу **Ctrl+Shift+R**. Новый заголовок — **«ПОСЛЕДНИЙ РУБЕЖ · ЦЕНА ВЫЖИВАНИЯ»**. Успешный push сам по себе не подтверждает завершение публикации.

Ограничения этого спринта: управление клавиатурой, конечные ресурсы, мгновенный сон без входа внутрь, без лечения; нет врагов, крафта, оружия, сложного инвентаря и мультиплеера. Рекомендации следующего спринта перечислены в отчёте и не реализованы заранее.
